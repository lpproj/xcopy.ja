FreeDOS XCOPY command version 1.9 (Japanese) 補足説明
-----------------------------------------------------

FreeDOS公式の XCOPY を日本語（シフトJIS）ファイル名対応したものとなります。
また、日本語メッセージファイルを同梱しています。
メッセージファイル XCOPY.JA を

* XCOPY.EXEと同じディレクトリ
* 環境変数NLSPATH上に設定したディレクトリ

のいずれかにコピーし、環境変数 LANG に表示言語を設定しておくことで、動作時のメッセージや"XCOPY /?"のヘルプが日本語で表示されるようになります。
（環境変数 LANG を設定していないときは、set LANG=JA が設定された場合と同じ動作になります）

公式版 XCOPY との動作の違い
---------------------------

/D: スイッチで日付を指定する際の年/月/日の順番が異なる場合があります。
公式版はつねに米国式 MM/DD/YY ですが、日本語版は DOS の国別情報から取得した日付フォーマットを使うように修正されています。日本語 DOS の場合、日本式 YY/MM/DD で日付を指定してください。


ソースのビルド
--------------

日本語対応版のビルドには以下のいずれかのコンパイラがおそらく必要です。

* OpenWatcom
* Borland C/C++ 4.0〜5.0（バージョン 3.1以下の Borland/Turbo C は不可）

Visual C++ 1.xやDigitalMars C++でもコンパイルできるかもしれません（未確認）。

OpenWatcomでビルドする場合は Makefile.ja をご利用ください。

    wmake -h -e -f Makefile.ja
